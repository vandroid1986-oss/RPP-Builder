Hasil Prompt AI 
Harap isi form di sebelah kiri dan klik tombol "Buat Prompt AI" untuk melihat hasil prompt di sini...

Prompt ini dirancang dengan instruksi berlapis guna memaksa AI menghasilkan format HTML asli lengkap dengan styling, kolom-kolom tabel, dan warna visual yang menarik tanpa harus tahu coding.

Bagaimana cara menggunakannya?

  1. Isi detail mata pelajaran, materi, dan tujuan di form kiri.
  2. Klik Buat Prompt AI untuk memformulasi instruksi khusus.
  3. Salin prompt yang dihasilkan menggunakan tombol Salin Prompt.
  4. Tempel (paste) prompt tersebut ke asisten AI pilihan Anda (Gemini, ChatGPT, Claude, dll).
  5. AI akan memproses RPP Anda secara instan dan mengeluarkannya dalam format HTML siap pakai!
